# Metodologia

## Tipo de pesquisa

Este trabalho caracteriza-se como uma pesquisa experimental e quantitativa, pois compara o desempenho de três algoritmos de ordenação por meio de experimentos e medições de tempo de execução.

## Algoritmos analisados

Serão analisados os algoritmos Gnome Sort, Tournament Sort e Pancake Sort.

## Conjuntos de dados

Serão utilizados conjuntos de dados compostos por nomes, com três tamanhos de entrada:

- 100.000 elementos;
- 250.000 elementos;
- 500.000 elementos.

## Métrica de avaliação

A principal métrica será o tempo de execução de cada algoritmo, medido em segundos.

## Procedimento experimental

Cada algoritmo será executado 10 vezes para cada tamanho de entrada. Os resultados serão registrados em arquivos CSV para permitir a análise e a comparação dos desempenhos.

Antes da comparação, será verificado se os resultados produzidos pelos algoritmos estão corretamente ordenados.

## Análise dos resultados

Os tempos registrados serão organizados em tabelas. Serão calculadas as médias dos tempos de execução para comparar o desempenho dos algoritmos nos diferentes tamanhos de entrada.
