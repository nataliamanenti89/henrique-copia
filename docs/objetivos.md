# Objetivos

## Objetivo geral

Comparar experimentalmente o tempo de execução dos algoritmos Gnome Sort, Tournament Sort e Pancake Sort na ordenação de conjuntos de dados de nomes com diferentes tamanhos de entrada: 100.000, 250.000 e 500.000 elementos.

## Objetivos específicos

- Apresentar o funcionamento dos três algoritmos de ordenação estudados.
- Preparar os conjuntos de dados utilizados nos experimentos.
- Implementar e testar os algoritmos selecionados.
- Executar os benchmarks com 10 repetições para cada algoritmo e tamanho de entrada.
- Registrar os tempos de execução obtidos nos experimentos.
- Calcular e comparar as médias dos tempos de execução.
- Analisar o comportamento dos algoritmos conforme o aumento do tamanho dos conjuntos de dados.
