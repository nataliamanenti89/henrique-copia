# Sorting Benchmark

Projeto de pesquisa e implementação de algoritmos de ordenação em Python.

O objetivo é comparar experimentalmente o desempenho dos algoritmos Gnome Sort, Tournament Sort e Pancake Sort, considerando diferentes tamanhos de conjuntos de dados compostos por nomes fictícios gerados com a biblioteca Faker.

Os experimentos utilizarão conjuntos de 100.000, 250.000 e 500.000 elementos, tendo como principal critério de avaliação o tempo de execução.
